# 00 · 学习地图 —— 怎么读这个项目

> 这本书配套的代码,是一座用纯 Python"造"出来的计算机世界:一台 CHIP-8
> 虚拟机、一台 RISC-V CPU、一个带系统调用的微操作系统。像 MIT 的 xv6 一样,
> 它存在的唯一目的就是**被读懂**。全书约 12 章,每章对应一个真实存在的
> 源码文件,章末有分级练习。

## 一、这个项目是什么

一层一层从下往上,每层都真实可跑:

```
 ┌─────────────────────────────────────────────┐
 │  你(键盘 / 终端)                            │
 ├─────────────────────────────────────────────┤
 │  watch.sh 实况画面  │  scope.sh 显微镜调试器 │
 ├─────────────────────────────────────────────┤
 │  微操作系统 kern:抢占调度 · 睡眠队列 ·       │
 │  邮箱 IPC · 系统调用(M/U 两级特权)          │
 ├─────────────────────────────────────────────┤
 │  外设:framebuffer · UART · 键盘 · CLINT 定时器│
 ├─────────────────────────────────────────────┤
 │  RISC-V CPU(RV32I + M 乘除 + Zicsr)         │
 ├─────────────────────────────────────────────┤
 │  自研汇编器 + zig cc 交叉编译的 C 程序        │
 ├─────────────────────────────────────────────┤
 │  Python 解释器(地基,不归我们管)            │
 └─────────────────────────────────────────────┘
```

热身线是 **CHIP-8**(1977 年的一台"迷你假想电脑",35 条指令,一个周末
能读完)——它教会你"虚拟机"这个词到底是什么意思。主线是 **RISC-V**:
同一套"取指-译码-执行"骨架放大重写,一路长出外设和操作系统。

## 二、怎么读(三遍法)

1. **跑起来**:每章开头都有一条命令,先跑,看到现象再读原理
2. **读章**:对照章里指名的函数(如 `Chip8.step()`、`handle_syscall()`)
   读真实源码——本书所有引用都用函数名,不用行号,永远不失效
3. **做练习**:章末 2~3 道分级练习(★ 改参数 / ★★ 加功能 /
   ★★★ 设计新机制)。练习是这个项目的"作业本"

## 四、环境与快速开始

只需要:Windows + WSL2 + Ubuntu(Python ≥ 3.10)。零第三方依赖、零 GPU。

```bash
git clone git@github.com:dazi9/computer-lab.git
cd computer-lab
(cd chip8 && python3 tests/test_cpu.py)      # 应显示 15/15
(cd riscv && python3 tests/test_rv.py)       # 应显示 21/21
python3 -m rv.emu programs/hello.asm         # 在自己 CPU 上跑出 Hello
wsl -- bash ~/computer-lab/riscv/watch.sh    # 实况围观内核(另开终端)
```

工具链(zig)不用手动装:第一次编译 C 时按提示运行
`python3 tools/fetch_zig.py` 即可自动下载到 `tools/zig`。

## 五、写作约定

- 引用代码一律用**函数/方法名**(如 `_draw()`、`wake_due_tasks()`),
  不用行号
- 伪代码用 ``` 代码块;真实命令都可直接复制执行
- 练习难度:★ 照着改 · ★★ 想着加 · ★★★ 自己设计
- 每章开头一句话说明"这章你会学到什么",结尾有"本章小结"
