## 一、什么是虚拟机:用软件扮演一台电脑

1977 年,个人电脑内存普遍只有几 KB,每台机器指令集还互不相同。游戏
开发者想出个主意:**设计一台"纸面电脑"**,指令集固定、谁都能写解释器,
游戏只对着纸面电脑编程——换个平台,只要移植一个小小的解释器。

这台纸面电脑就是 CHIP-8。用今天的话说:它是一套**字节码规范**,
`cpu.py` 就是它的解释器。你玩的弹跳小球,是一条条 2 字节指令喂给
解释器"演"出来的。

## 二、这台电脑的身体清单

打开 `cpu.py` 的 `Chip8.__init__()`——构造函数就是"装机清单":

| 部件 | 规格 | 为什么是它 |
|---|---|---|
| 内存 | 4096 字节 | 1977 年机器就几 KB,4KB 是奢侈 |
| 寄存器 | V0~VF,各 8 位 | 16 个够用;VF 兼作进位/碰撞标志 |
| PC | 程序从 0x200 开始 | 前 512 字节留给当时的解释器住(历史包袱) |
| 栈 | 16 层 | 只为子程序调用,够用 |
| 定时器 | DT、ST 各 8 位,60Hz 递减 | DT 延时、ST 控制蜂鸣时长 |
| 屏幕 | 64×32 单色 | 每像素 1 字节,亮=1 |
| 键盘 | 16 键(0~F) | 游戏 ENOUGH |

注意两个**约定**:字体(0~F 的字模)常驻在内存 0x050;程序入口固定
0x200。真实硬件的很多"规矩",本质都是历史约定——CPU 之于软件,
约定即现实。

## 三、心跳:取指-译码-执行

`step()` 是整台电脑的心脏,只有三拍:

```python
op = (self.mem[self.pc] << 8) | self.mem[self.pc + 1]   # 取指:2 字节拼 1 条
self.pc = (self.pc + 2) & 0xFFF                          # PC 默认走 2 字节
self._exec(op)                                           # 译码+执行
```

三条铁律,所有 CPU(包括后面我们自己造的 RISC-V)都是这个节奏:

1. **取指**:从 PC 指的内存把指令拿出来(CHIP-8 每条 2 字节,大端)
2. **PC 前移**:默认指向下一条(跳转类指令会改写它)
3. **执行**:看指令是什么,照做

## 四、解剖一条指令:0x6012

`6XNN` = "把数 NN 放进寄存器 VX"。0x6012 拆开:

```
 6    0    1    2
┌────┬────┬────────┐
│ 族 │寄存器│ 数据   │
│ 6  │ V0  │ 0x12   │
└────┴────┴────────┘
含义:V0 ← 0x12
```

最高位 6 是**指令族**(做什么),后面是**操作数**(对谁做、用什么数据)。
CHIP-8 的 35 条指令按族分成五大家族:

| 家族 | 高位 | 干什么 | 例子 |
|---|---|---|---|
| 数据 | 6, 7, 8 | 寄存器读写与算术 | `6XNN` `8XY4` |
| 跳转 | 1, 2, B | 改 PC | `1NNN` `2NNN` |
| 分支 | 3, 4, 5, 9 | 比较后跳 | `3XNN` |
| 内存 | A, FX55/65 | I 寄存器批量搬 | `FX55` |
| 绘图/IO | D, E, F | 屏幕、按键、定时器 | `DXYN` |

对照 `_exec()` 里的 if/elif 大链条——每条分支就是一个指令族。
(第 04 章会看到 RISC-V 用 `decode()` 表驱动译码,那是另一种风格,
各有优劣。)

## 五、XOR 绘图的魔法

`_draw()` 是最有游戏味的一条指令:把一个 8×N 的"精灵"按位**异或**到
屏幕上。妙处在于:同一个函数,画上去是它,**再执行一次就擦掉了**
(任何位 XOR 两次等于没变)。

```python
self.display[idx] ^= 1        # 亮变灭、灭变亮
```

弹跳小球的演示程序就是这么"擦旧画新"的:先 XOR 画在旧位置,
延时几帧,再 XOR 擦掉,位置 +1,循环。**动画 = 快速地擦与画**。
移动时若撞上已亮的像素,VF 寄存器记 1(碰撞检测,游戏用来判"打中了")。

## 六、时间的心跳:60Hz 定时器

`tick()` 每帧把 DT、ST 各减 1。主循环(见 `run_interactive()`)
每秒调 60 次——游戏逻辑靠"等 DT 变 0"来控制节奏,这就是最朴素的
帧率控制。真实操作系统里你会看到一个强化版:定时器中断(第 07 章)。

## 本章小结

- 虚拟机 = 用软件按"纸面规范"扮演一台电脑;`__init__` 是装机清单
- 一切 CPU 的心跳都是:取指 → PC 前移 → 执行
- 指令 = 族 + 操作数;35 条指令按五大家族理解,不必死记
- XOR 绘图:画与擦是同一个操作;动画就是快速擦画
- 定时器给"死循环的电脑"带来了时间
