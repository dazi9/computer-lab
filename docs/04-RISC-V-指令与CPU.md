## 一、三个跨越

| | CHIP-8 | RISC-V(RV32I) |
|---|---|---|
| 寄存器 | V0~V15,8 位 | x0~x31,32 位 |
| 指令长度 | 恒 2 字节 | 恒 4 字节(基础版) |
| 身份 | 纸面规范 | 工业界真实 ISA,有规范文档 |

第三行最关键:RISC-V 是**真处理器**(树莓派级到服务器)用的语言。
我们造的不是玩具 CPU,而是一台与真实世界对话的机器——后面 zig cc
编译的 C 程序,和真实工具链产物格式完全一致。

## 二、32 个寄存器与 x0 恒零

RISC-V 有 32 个寄存器。它们有两个名字:编号 `x0~x31` 和 ABI 助记名
(`zero ra sp t0-t6 s0-s11 a0-a7`)——名字背后是**使用约定**:
`a0~a7` 传参数、`ra` 存返回地址、`sp` 是栈指针。

最妙的设计是 **x0 恒等于 0,且写它无效**:

```python
def _wreg(self, rd, val):
    if rd:                           # x0 恒为 0
        self.x[rd] = val & MASK32
```

听起来像浪费一个寄存器?恰恰相反:`addi x0, x0, 0` 就是 nop、
`sub x0, x0, x5` 得到"取负"…**常数 0 免费送给每条指令当操作数**,
一整个指令族因此消失。好的 ISA 设计在做减法。

## 三、六种指令格式:立即数为什么要"打散"

所有 4 字节指令共享一个骨架:低 7 位永远是**操作码**(做什么),
然后按需要塞寄存器和立即数。六种格式:

```
R: f7 rs2 rs1 f3 rd  op   ← 三寄存器运算(add/sub/sll…)
I:     imm rs1 f3 rd  op   ← 立即数 + 访存 + jalr
S: imm5 rs2 rs1 f3 imm0 op  ← store(sb/sh/sw)
B: 打散的 imm rs2 rs1 f3 打散的 imm op  ← 条件分支
U:        imm20      rd  op   ← lui/auipc(大常数)
J: 打散的 imm        rd  op   ← jal(无条件跳)
```

最臭名昭著的是 **B/J 型**:立即数位被拆得七零八落(比如 J 型的
imm[10:1] 落在指令的 [30:21])。为什么?历史设计权衡——让高频信号线
位置固定,简化硬件布线。代价是:手写编码/译码极易错位。

本项目用**双保险**锁死它:

1. `tests/test_rv.py` 里放着手算的规范编码(如 `beq x1,x2,8`
   必须等于 `0x00208463`)
2. `decode()` 是**唯一真相**:CPU 执行和单元测试共用它,
   编码↔译码永远对称

这是我们修 CHIP-8 译码 bug 时学到的教训,在 RISC-V 上制度化了。

## 四、几条"聪明"的指令

- **`jal rd, offset`**:跳转同时把返回地址(pc+4)写进 rd——
  **函数调用只需一条指令**。`jalr` 同理但目标来自寄存器,
  两者配合实现 call/return
- **`lui rd, imm20` + `addi`**:一个 32 位常数拆成"高 20 位 +
  低 12 位"两条指令装载(`li` 伪指令干的就是这事)
- **`sltu` vs `slt`**:同一个"小于"运算,有符号/无符号各一条——
  硬件省掉一个标志位,软件自己选语义
- **除零不报错**:`div x, y, 0` 返回 -1 而不是异常——RISC-V 规定
  "除零给个确定值",硬件省掉一整条异常处理通路(M 扩展,见
  `_div()` 的注释)

## 五、心跳,放大版

`RV32.step()` 和 CHIP-8 的 `step()` 逐拍对照:

```python
inst = int.from_bytes(...)   # 取指:4 字节,小端
f = decode(inst)             # 译码:字段 + 立即数(唯一真相)
next_pc = self.pc + 4        # PC 默认前移 4
... 按 opcode 分发执行 ...    # 执行:40+ 条指令
self.pc = next_pc
```

读 `_exec` 分发链的建议:**先只读 6 条**(addi/jal/分支/lw/sw/ecall),
其余按需查。40 条指令里没有一条是魔法。

## 本章小结

- 心跳不变,乐谱升级:32 位、4 字节、32 寄存器、真实 ISA
- x0 恒零是设计哲学:常数 0 免费进每条指令
- 六种格式共享"低 7 位操作码";B/J 型立即数打散是硬布线权衡,
  用"规范编码基准 + decode 唯一真相"双保险锁死
- jal/jalr 一条指令完成函数调用;除零不报错是硬件视角的取舍
